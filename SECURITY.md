# Security Policy

## Supported Versions

This repository is a sandbox under active development.

| Version | Supported |
| --- | --- |
| main | yes |
| historical snapshots | no |

## Reporting a Vulnerability

Please do not report security issues in public GitHub issues.

Use one of the following private paths:

1. Open a private GitHub security advisory (if enabled).
2. Contact repository maintainers directly.

When reporting, include:

- A clear description of the issue.
- Steps to reproduce.
- Expected vs actual behavior.
- Potential impact.
- Suggested remediation, if known.

You can expect a best-effort response. Because this is a sandbox repository,
response and patch timelines are not guaranteed.
