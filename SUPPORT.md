# Support

## Purpose

This repository is a sandbox for architecture and pattern experiments.

Because it is not a production library, support is best effort.

## Getting Help

1. Open a GitHub issue using the provided templates for bugs or feature requests.
2. Include clear reproduction steps, expected behavior, and actual behavior.
3. If your report is security-sensitive, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

## What To Expect

- No strict SLA for responses.
- Rapid iteration and potentially breaking changes.
- Priority on clarity, experiments, and learning outcomes.
